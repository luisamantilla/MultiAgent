# Examples and Tutorials

## Purpose
End-to-end examples, tutorials, and demonstrations of the multi-agent biological modeling system.

## Structure

### `/end_to_end/` - Complete Workflow Examples
- `influenza_modeling/` - Complete influenza modeling workflow from literature to simulation
- `tumor_tcell_interaction/` - Tumor-T cell interaction modeling example
- `pathway_discovery/` - Biological pathway discovery and validation example

### `/tutorials/` - Step-by-Step Learning Materials
- `getting_started.ipynb` - Basic system usage and concepts
- `biological_modeling_101.ipynb` - Introduction to biological modeling workflow
- `parameter_extraction_guide.ipynb` - Parameter extraction from PDFs tutorial
- `code_generation_tutorial.ipynb` - Code generation and execution tutorial

### `/demos/` - Interactive Demonstrations
- `web_demo/` - Flask-based web interface demonstration
- `jupyter_demo/` - Jupyter notebook-based interactive demo
- `cli_demo/` - Command-line interface demonstration
